# 句型速查库


### A. 开头与立场

- It is a controversial issue whether …
- Many people argue that [A], but some think otherwise, saying [B].
- Despite the widespread belief that [A], many are skeptical about its validity.
- While some people advocate for [A], others question its effectiveness. They contend that [B].
- Although proponents of [A] claim that it brings numerous benefits, critics argue that [B] is more advantageous.
- However, I firmly believe (that) …

### B. 推进与分析

- 首论据：To begin with / First and foremost / For one thing / To start with / In the first place
- 次论据：Moreover / Besides / In addition / What is more / For another / Furthermore
- 分析：As a consequence / That is to say / As a matter of fact / In other words / To be specific
- 收束：By doing so / In this sense

### C. 双边与让步

- Those who stand up for / side with / are in favor of / are strong advocates of … argue / insist / maintain / assert that …
- The objections of … come mainly from those who claim / contend / are convinced that …
- It is undoubtful / indubitable that …（只让一句）
- However, this view is flawed.
- 反问收尾：What is the point of …?（全篇一次）

### D. 分析解决

- There are some practical reasons why …
- The biggest concern is that …
- A further example comes mainly from …, where …
- Another situation involves … / Hardly can one more factor remain untouched.
- 主语 be well advised / highly recommended to do …
- It is high time for … to do / that …（从句过去式）

### E. 置换与高级结构

- if / once / provided that / supposing / but for / without / unless / in case of
- 延展维度：程度、范围、领域、对象、时间 + 反向假设
- think / find / make + it + adj + to do / that …
- Hardly can … ; Not only are …, but they also …
- Although … may not be flawless, its advantages in terms of … far outweigh its limitations.

### F. 事例句

- A prime example of this is [人物], who [成就]. His/Her contribution highlights [观点]. This demonstrates that [论点].
- One historical figure that supports this argument is [人物], whose work in [领域] transformed [影响]. This proves that [观点].
